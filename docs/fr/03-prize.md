# 3. Usage pour des récompenses

Un système de récompense peut utiliser le TWAB pour pondérer les droits selon la durée de détention. Le contrôleur fournit la mesure ; le contrat de prix ou de tirage reste séparé.

Ce chapitre relie le mécanisme au parcours d’exécution et signale les invariants que l’intégrateur doit préserver.
