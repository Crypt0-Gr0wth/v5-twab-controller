# 4. Limites et intégration

Les changements de balance, les timestamps et les coûts de lecture doivent être anticipés. Ce parcours couvre le mécanisme du dépôt, sans exécuter de test ni installer de dépendance.

Ce chapitre relie le mécanisme au parcours d’exécution et signale les invariants que l’intégrateur doit préserver.
